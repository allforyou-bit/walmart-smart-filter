## What It Does

Walmart search results mix **Walmart-sold items** with **third-party marketplace sellers**. This extension fixes that — and finds the best deals for you automatically.

| Feature | Description |
|---|---|
| 🔵 **Walmart Direct Filter** | One click removes all third-party sellers from search results |
| 🏷️ **Deal Badges** | Clearance, Rollback, Reduced Price shown with exact **discount %** |
| 📊 **Live Deal Stats** | Popup shows average & best savings % on the current page |
| 🔍 **Deal Preview** | Hover any count to see thumbnails, prices & ratings — sorted best first |
| ✂️ **Min. Savings Filter** | Show only deals ≥ 10%, 20%, or 30% off |
| 🚚 **Shipping & Pickup** | Filter to free 2-day shipping or in-store pickup items |
| ⌨️ **Keyboard Shortcut** | `Ctrl+Shift+W` to toggle filter instantly |

## Installation

### From Chrome Web Store *(recommended)*
[Add to Chrome →](https://chromewebstore.google.com/detail/walmart-smart-filter/EXTENSION_ID)

### Manual Install (Developer Mode)
1. Download the latest [release ZIP](https://github.com/allforyou-bit/walmart-smart-filter/releases/latest)
2. Unzip the file
3. Open Chrome → `chrome://extensions/`
4. Enable **Developer mode** (top right toggle)
5. Click **Load unpacked** → select the unzipped folder

---

## How to Use

1. Go to **walmart.com** and search for anything
2. The extension automatically filters results and highlights deals
3. Click the extension icon to see your **deal dashboard**
4. Hover over Clearance / Rollback / Reduced / Best Seller counts for a **deal preview**
5. Use `Ctrl+Shift+W` to quickly toggle the Walmart Direct filter
