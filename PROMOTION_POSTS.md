## Reddit — r/frugal

**Title:**
I made a free Chrome extension that filters Walmart search to Walmart Direct only + highlights Clearance/Rollback deals with exact discount %

**Body:**
```
Hey r/frugal,

I got tired of Walmart search results mixing in third-party marketplace sellers
at inflated prices, so I built a Chrome extension to fix it.

**What it does:**
- One click filters results to Walmart-sold items only (no 3rd party sellers)
- Highlights Clearance, Rollback, and Reduced Price items with colored borders
- Shows the exact discount % on each deal card (e.g. "Clearance · −43%")
- Hover the extension icon to see a live deal dashboard with product thumbnails,
  prices, star ratings — sorted by best savings first
- Filter by minimum savings: only show deals ≥ 20% off, etc.
- Keyboard shortcut: Ctrl+Shift+W to toggle filter instantly

**Completely free.** No account, no data collected.

GitHub: https://github.com/allforyou-bit/walmart-smart-filter
Chrome Web Store: https://chromewebstore.google.com/detail/walmart-smart-filter/emkhcglnplcglmbckhcajioeglkoammn

Happy to answer questions or take feature suggestions!
```
